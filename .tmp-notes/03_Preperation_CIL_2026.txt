entries satisfy A = AT, meaning aij = aji for all indices i, j.
Theorem (Real eigenvalues)
Every real symmetric matrix A has only real eigenvalues.
Theorem (Orthogonality of eigenvectors)
Eigenvectors of a real symmetric matrix corresponding to distinct

===== PAGE 19 =====
The ”learning” in Machine Learning
Machine learning models are trained by optimizing a loss function:
a scalar value that measures how well the model ﬁts the data.
Even when multiple criteria are involved, they are typically
combined into a single scalar objective.
The goal of learning is to adjust the model parameters so as to
minimize (or maximize) this objective. The standard approach is to
update the parameters in the direction indicated by the gradient of
the loss with respect to those parameters.
