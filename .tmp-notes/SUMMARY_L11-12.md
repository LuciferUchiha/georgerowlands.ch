## LECTURE 11 (VAE part, pages 39-67)

### Latent variable models (p40-41)
- Marginal likelihood p_theta(x) = int p_theta(x,z) dz = int p(z) p_theta(x|z) dz.
- prior p(z) over latents, conditional p_theta(x|z). Simple factors -> complex marginal.
- Marginal p_theta(x) and posterior p_theta(z|x) intractable.
- Introduce inference model (encoder) q_phi(z|x) approx p_theta(z|x).
  (mu, log sigma) = EncoderNN_phi(x); q_phi(z|x) = N(z; mu, diag(sigma)).

### ELBO derivation (p45) -- CLEAN, worth adding
log p_theta(x) = E_{q_phi(z|x)}[log p_theta(x)]                 (x const wrt z)
  = E_q[ log p_theta(x,z)/p_theta(z|x) ]                        (Bayes: p(x)=p(x,z)/p(z|x))
  = E_q[ log ( p_theta(x,z)/q_phi(z|x) * q_phi(z|x)/p_theta(z|x) ) ]   (mult/div by q)
  = E_q[ log p_theta(x,z)/q_phi(z|x) ] + E_q[ log q_phi(z|x)/p_theta(z|x) ]
  >= E_q[ log p_theta(x,z)/q_phi(z|x) ]                         (2nd term = KL(q||p(z|x)) >= 0)
  = E_q[ log p_theta(x,z) - log q_phi(z|x) ] := L_{theta,phi}(x)  (ELBO)

### ELBO = reconstruction - KL (p47)
Use p_theta(x,z) = p_theta(x|z) p(z):
L = E_q[log p_theta(x|z) + log p(z) - log q_phi(z|x)]
  = E_q[log p_theta(x|z)]            (reconstruction)
    - E_q[log q_phi(z|x)/p(z)]       (= KL(q_phi(z|x) || p(z)), regularization)

### Gradient wrt theta is easy (p50)
grad_theta L = grad_theta E_q[log p_theta(x,z) - log q_phi(z|x)]
  = E_q[grad_theta(...)]             (q does NOT depend on theta -> swap grad & E)
  ~= grad_theta(log p_theta(x,z)), z ~ q_phi(z|x)    (Monte Carlo, 1 sample)
  = grad_theta log p_theta(x,z)      (log q_phi term doesn't depend on theta)
  [= grad_theta (log p_theta(x|z) + log p_theta(z))]

### Reparameterization: the problem (p52)
Need grad_phi E_{q_phi(z|x)}[f(z)], f(z)=log p_theta(x,z) - log q_phi(z|x).
Problem: q_phi(z|x) ITSELF depends on phi -> cannot move grad_phi inside E,
cannot backprop through stochastic sampling. (x->Enc phi->mu,sig->[sample z X grad blocked]->Dec->xhat)

### Reparameterization: the idea (p53)
z = g(eps,phi,x) = mu_phi(x) + sigma_phi(x) (hadamard) eps, eps ~ N(0,I).
Randomness isolated in eps (no params); z differentiable fn of phi. grad_phi flows freely.

### VAE learning, two gradient paths (p56)
- Generative (theta, decoder): grad flows directly through log p_theta(x|z); z fixed sample from q_phi.
  grad_theta L = E_q[grad_theta log p_theta(x|z)] ~= grad_theta log p_theta(x|z), z~q_phi.
- Inference (phi, encoder): reparam z=mu+sig(*)eps so grad passes through deterministic path.
  grad_phi L ~= grad_phi log p_theta(x|z) - grad_phi KL(q_phi||p), eps~N(0,I).
- Joint SGD/Adam on minibatches, 1 noise sample eps per datapoint per step.

### What z represents / factors of variation (p58-60)
- Encoder compresses x in R^{HxWx3} to z in R^d, d << HWC. ELBO trade-off: reconstruction keeps info,
  KL pulls z toward smooth prior N(0,I) -> z can't store pixel detail, must capture underlying factors.
- Factors of variation: real data generated by few underlying causes (rotation, expression, hair...).
  Hope: each dim of z captures one independent factor; moving along one axis changes one attribute.
- Disentanglement: different dims of z encode different independent factors. Entangled = mixed axes.
  Test: fix z (a face), vary one coord z_i holding others fixed, decode, see if ONE attribute changes.
- Vanilla VAEs do NOT guarantee disentanglement; beta-VAE encourages it (weight on KL to decorrelate).

### VAE take-home (p64-65)
Give: principled likelihood training via ELBO; structured latent (smooth interp, arithmetic); interpretable
factors. Open: blurry samples (Gaussian decoder averages over modes); disentanglement not guaranteed;
ELBO only a lower bound (gap to true likelihood). Extensions: beta-VAE, VQ-VAE (discrete), hierarchical, NF priors.

## LECTURE 12 (GAN + WGAN)

### Is likelihood the answer? (p7)
MLE works BUT limits transformation maps (AR), needs approx ELBO (VAE). Is likelihood the right proxy
if the goal is INDISTINGUISHABILITY of distributions? (annot: "not perfect, otherwise mode collapse")

### Generation as classification (p8)
Mixture model: p(x,Y;theta) = (Y/2) p(x) [true, Y=1] + ((1-Y)/2) p(x;theta) [synthetic, Y=0], Y in {0,1}.
Y = binary indicator. Train classifier to separate -> pushes generator to erase the boundary.

### Fixed discriminator (p9)
Discriminator pi: R^n -> [0,1], pi(x) = Phat{Y=1|x} ~ P{Y=1|x}.
Logistic (classification) log-likelihood:
ell(theta; pi) = E_{(x,Y)~p(x,Y;theta)}[ Y ln pi(x) + (1-Y) ln(1-pi(x)) ]
  = 1/2 E_{x~p}[ln pi(x)]  +  1/2 E_{x~p_theta}[ln(1-pi(x))]
  (= 1/2 int ln pi(x) p(x) dx  [const wrt theta]  + 1/2 int ln(1-pi(x)) p(x;theta) dx [theta-dep])
Generator only sees the 2nd (theta-dependent) term.

### Bayes-optimal discriminator (p11-12)
pi*(x) = P{Y=1|x} = p(x) / (p(x) + p(x;theta))   (class posterior, Bayes rule).

### JS divergence (p13) -- KEY derivation
Plug pi* into ell:
ell(theta) = int (p(x)/2) ln( p(x)/(p(x)+p(x;theta)) ) dx + int (p(x;theta)/2) ln( p(x;theta)/(p(x)+p(x;theta)) ) dx
  = 1/2 int p(x) ln( p(x)/(1/2(p+p_theta)) ) dx - 1/2 ln2   (pull 1/2 out of the denom -> -ln2 per term)
    + 1/2 int p_theta ln( p_theta/(1/2(p+p_theta)) ) dx - 1/2 ln2
  = 1/2 KL(p || 1/2(p+p_theta)) + 1/2 KL(p_theta || 1/2(p+p_theta)) - ln2
  = JS(p, p_theta) - ln2.
So minimizing ell over theta = minimizing JS(p, p_theta). (-ln2 const, ignore.)

### KL & JS defs (p14)
KL(p||q) = int p ln(p/q) dx = E_p[ln p - ln q] >= 0. NOT symmetric, unbounded.
JS(p||q) = 1/2 KL(p||1/2(p+q)) + 1/2 KL(q||1/2(p+q)). Symmetric, bounded: 0 <= JS <= ln2 (= avg KL to mixture).

### Conclusion (p15)
Generator minimizing logistic loss vs Bayes-optimal discriminator = minimizing JS(p_data || p_theta).
PROBLEM: we don't know p (Bayes-optimal pi* needs it). How to define discriminator practically?

### Learning the discriminator (p16)
phi parameterizes family pi(x;phi). ell(theta;pi*) >= sup_phi ell(theta; pi(.;phi))
  = sup_phi { 1/2 E_{x~p_data}[ln pi(x;phi)] + 1/2 E_{x~p_theta}[ln(1-pi(x;phi))] }.
Find discriminator with HIGHEST logistic log-likelihood (best approx to Bayes-optimal).

### Saddle point / GAN (p17)
theta* = argmin_theta { max_phi ell(theta;phi) } [worst-case loss], phi* = argmax_phi ell(theta*;phi).
Generator & discriminator are adversaries: optimize common objective in opposite directions.

### Vanishing gradients (p18)
Original generator obj: min_theta int ln(1-pi(x;phi)) p(x;theta) dx -> flat gradients early
(initial weak generator very easy to classify -> ~0 gradient).
Non-saturating fix: max_theta int ln pi(x;phi) p(x;theta) dx -> stronger gradients when pi small.
(No longer exactly minimizes JS, but more stable.)

### Alternating gradients (p19)
theta_{t+1} = theta_t - eta grad_theta ell(theta_t,phi_t)
phi_{t+1} = phi_t + eta grad_phi ell(theta_{t+1},phi_t)  [asynchronous] OR ell(theta_t,phi_t) [synchronous].
Naive alternating updates often fail to converge / diverge.

### Extragradient (p20, Korpelevich 1977)
Step1 lookahead: theta_{t+1}=theta_t - eta grad_theta ell(theta_t,phi_t); phi_{t+1}=phi_t + eta grad_phi ell(theta_t,phi_t).
Step2 midpoint: theta_{t+2}=theta_t - eta grad_theta ell(theta_{t+1},phi_{t+1}); phi_{t+2}=phi_t + eta grad_phi ell(theta_{t+1},phi_{t+1}).
Intermediate step = better direction, reduces cycling.

### Evaluation (p21)
No tractable likelihood; want quality AND diversity; domain-specific/subjective.
Human judgment (expensive); approx likelihood (bits/dim, crude); Inception Score IS (favors sharpness, ignores
diversity); Frechet Inception Distance FID (better, still heuristic); cross-testing G vs D (relative);
duality gap (theory, hard). No single metric satisfactory.

### Architectures
DCGAN 2015 (p23): generator = deconvolution/transposed-conv blocks instead of linear layers;
100-dim z -> project&reshape -> conv stack -> 64x64x3 image. StyleGAN 2019 (p25, nvidia): tune individual features.

### GAN summary (p26): goal, mixture classification, minimax, theory (Bayes-opt -> JS), challenges.

## WASSERSTEIN GAN (p27-49)

### Diagnosis (p28): maybe the problem is the DIVERGENCE (JS), not the architecture.

### Parallel-lines example (p29)
Z ~ U[0,1]. p = dist of (0,Z), p_theta = dist of (theta,Z). For theta != 0 supports DISJOINT.
Mixture m=1/2(p+p_theta) = 1/2 p on supp(p), 1/2 p_theta on supp(p_theta).
KL(p||m) = int p ln(p/(1/2 p)) = ln2; KL(p_theta||m)=ln2 => JS(p,p_theta) = ln2 (CONSTANT in theta, no gradient).

### Transport plan / Wasserstein metric (p31)
Transport plan gamma: how much mass moves from each x (in p) to each y (in p_theta).
W(p,p_theta) = inf_{gamma in Pi(p,p_theta)} E_{(x,y)~gamma} ||x - y||.
Pi(p,p_theta) = joint distributions with marginals p and p_theta. (= min average transport distance.)

### JS vs Wasserstein (p32)
JS(p,p_theta) = ln2 if theta!=0 else 0 (step, flat -> no GD signal).
W(p,p_theta) = |theta| (V-shape, usable gradient pointing to optimum).

### KR duality (p33)
Primal (inf over couplings) intractable. Kantorovich-Rubinstein:
W(p,p_theta) = sup_{||f||_L <= 1} { E_{x~p}[f(x)] - E_{x~p_theta}[f(x)] }.
Search for potential f: LARGE on real, SMALL on generated, 1-Lipschitz (not changing too fast).

### KR duality proof sketch (p34-36)
(1) Primal is an LP: inf_{gamma>=0} int gamma(x,y)||x-y|| dxdy s.t. int gamma dy = p(x), int gamma dx = p_theta(y).
    Lagrange multipliers f(x), g(y):
    inf_{gamma>=0} sup_{f,g} int gamma||x-y|| + int f(x)(p(x)-int gamma dy)dx + int g(y)(p_theta(y)-int gamma dx)dy.
(2) Group gamma terms: inf_gamma sup_{f,g} E_p[f] + E_{p_theta}[g] + int [||x-y|| - f(x) - g(y)] gamma dxdy.
    Swap inf/sup (strong duality). Turn inner inf over gamma>=0 into a CONSTRAINT to avoid -inf:
    sup_{f,g} E_p[f] + E_{p_theta}[g]  s.t.  forall x,y: f(x)+g(y) <= ||x-y||.
(3) Constraint => g(x) = -f(x); and f is 1-Lipschitz (f(x)-f(y) <= ||x-y||).
    Insert: W = sup_{||f||_L<=1} E_p[f] - E_{p_theta}[f].

### Why W usable (p37)
Thm1 (Arjovsky 2017): g_theta continuous in theta => W continuous; g_theta locally Lipschitz (any FF net)
=> W continuous everywhere, differentiable almost everywhere (can compute gradients).
Thm2: JS convergence => W convergence (W weaker than JS => easier for p_theta to converge under).

### Discriminator vs Critic (p40)
We call dual f a CRITIC. Discriminator(GAN): outputs probability, sigmoid, trained as classifier, "is this real?"
Critic(WGAN): outputs real-valued score, NO sigmoid, estimates dual objective, "how much more real?".

### Enforce Lipschitz: weight clipping (p41)
w <- clip(w, -c, c) after every critic update (c=0.01). Bounded box => K-Lipschitz for some K.
Arjovsky verdict: "a clearly terrible way to enforce a Lipschitz constraint." c too large -> slow; too small -> vanishing grad.

### Enforce Lipschitz: gradient penalty WGAN-GP (p42, Gulrajani 2017)
L = E_p[f(x)] - E_{p_theta}[f(x)] + lambda E_{xhat ~ P_xhat}[ (||grad_xhat f(xhat)||_2 - 1)^2 ].
1-Lipschitz f has ||grad f|| <= 1; penalize at points xhat interpolated between real and fake.

### WGAN algorithm (p43)
Hyperparams: lr alpha, clip c, batch m, n_critic = 5. Repeat:
(1) Critic loop t=1..n_critic: sample {x_i}~p, {z_i}~p(z);
    g_phi <- grad_phi [ (1/m)sum f(x_i;phi) - (1/m)sum f(g_theta(z_i);phi) ];
    phi <- phi + alpha RMSProp(phi,g_phi); phi <- clip(phi,-c,c).
(2) Generator: sample {z_i}~p(z); g_theta <- -grad_theta (1/m) sum f(g_theta(z_i);phi);
    theta <- theta - alpha RMSProp(theta,g_theta).
(annot: use RMSProp not Adam -- Adam momentum breaks it; "a bit like RL".)

### Train critic to optimality (p44)
Standard GAN paradox: too-good discriminator saturates => generator grad vanishes => delicate balancing.
WGAN INVERTS: W differentiable a.e. => better critic => more reliable gradient. Want critic well-trained
(~5 critic steps/generator step, near optimal). Balancing act gone.

### Mode collapse (p45): JS rewards it (overlap minimum, missing modes free), W punishes it (transport cost;
missing mode is one descent away).

### Why WGAN fixes things (p46)
1. No vanishing gradients (Lipschitz critic cannot saturate).
2. Informative loss (near-optimal critic loss ~ Wasserstein distance, correlates with sample quality).
3. Less mode collapse (W exposes the gap as a gradient pushing G outward).

### Outlook (p48): Diffusion dominates sample quality/stability. GANs not gone: fast single-step sampling;
adversarial objectives inside diffusion-distillation/consistency models. "Not GANs lost - field absorbed ideas."

### WGAN summary (p49): diagnosis (divergence not model); transport->critic via KR; enforce Lipschitz
(clipping->grad penalty); algorithm (train critic near-optimal n_critic~5); payoff (informative loss, no
vanishing grad, less mode collapse).
