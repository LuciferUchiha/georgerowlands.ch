Proof: Convexity and Cone Property of PSD Matrices
1. Convexity:
↭Let A, B be two PSD matrices, consider the convex
combination C = εA + (1 ⇑ε)B for some ε ⇒[0, 1].
↭For any vector x:
xTCx = xT(εA + (1 ⇑ε)B)x = εxTAx + (1 ⇑ε)xTBx ↖0.
↭Thus, C is PSD, proving convexity.
2. Cone Property:
↭Let A be a PSD matrix and let ϖ > 0 be a scalar.
↭Then for any vector x:
xT(ϖA)x = ϖ(xTAx) ↖0.
↭Thus, ϖA is PSD, proving the cone property.
