===== PAGE 7 =====
Caveats about Latent Variables
↭Identiﬁability: di!erent parameter settings can yield the
same p(x).
E.g. permuting cluster labels gives the same mixture.
↭No guaranteed interpretability: latent variables capture
statistical structure, not necessarily human-understandable
concepts.
“Semantic meaning” is a modeling hope, not a guarantee.
↭Entanglement: individual latent dimensions may mix
multiple factors of variation.
E.g. a single zj might encode both object shape and color
simultaneously — disentanglement is an active research area
(Locatello et al., 2019).
↭Model misspeciﬁcation: the true data generating process
may not match our assumed model family at all.

===== PAGE 27 =====
EM Algorithm — Summary
EM: iteratively maximize the Evidence Lower Bound (ELBO)
1. Initialize parameters ε(0), ω(0)
2. Repeat until convergence:
↭E-step: compute posteriors qtz = P(Zt = z|xt;ε)
↭M-step: update ε,ω to maximize ELBO given q
3. Output: parameters ε↓, ω↓and soft assignments q↓
Key properties:
↭Log-likelihood never decreases (guaranteed monotonic
improvement)
↭Converges to a local maximum (not necessarily global)
↭General-purpose: works for any mixture model where
component MLE is tractable

From k-means to Soft Clustering
k-means has important limitations:
↭Hard assignments: every point belongs to exactly one cluster
— no notion of uncertainty
↭Spherical clusters: implicitly assumes equal-size, isotropic
clusters
↭No probabilistic model: no likelihood, no principled model

GMM generalizes k-means: each cluster has its own mean µz,

===== PAGE 42 =====
Practical Considerations
↭Initialization matters: EM converges to a local maximum.
Common strategies: k-means++ initialization, multiple
random restarts, pick the run with highest ﬁnal log-likelihood.
↭Choosing k: the number of components is a hyperparameter.
Model selection criteria: BIC (Bayesian Information
Criterion), AIC, or cross-validation on held-out log-likelihood.
↭Numerical stability:
Use the log-sum-exp trick when computing responsibilities to
avoid underﬂow. Watch for singularities: if a Gaussian
collapses onto a single point, |!z| ⇒0. Regularize with a
small diagonal term.
